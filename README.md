# 航海王中文版单人练习桌

目标：浏览器打开即可玩；一人操作双方，原卡图、中文效果、适配手机，规则自动结算。当前是开发中的本地版本，尚未部署为手机可访问的正式链接。

## 当前内容

- 来自用户提供的 Windows 游戏的 2,857 张卡牌定义，已提取原卡图；其中 3 张原文件缺图。
- 2,832 张已匹配官方中文说明，余下 25 张待核对。
- 起手、回合、DON!!、攻击、阻挡、反击、生命触发、胜负、撤销与本地存档。
- 部分登场／主动／被动／替代效果已迁移。卡组包含未支持规则时会阻止开局，避免静默跳过效果。
- 规则字段审计目前为 2,297 张结构可处理、560 张仍有未迁移字段。此数字不代表逐张通过规则正确性验证。

## 本机运行与验证

在项目目录执行 `python -m http.server 4173 --bind 127.0.0.1 --directory dist`，然后在同一台电脑打开 `http://127.0.0.1:4173`。这个地址不是公网链接，手机不能用它访问电脑。

- 引擎验证：`node --test tests/engine.test.mjs tests/playthrough.test.mjs tests/rules-expansion.test.mjs tests/sound.test.mjs tests/end-turn.test.mjs`
- 浏览器验证：先启动上面的服务器，再执行 `python tools/qa_browser.py`（需要 Playwright 与 Chromium）。
- 规则覆盖报告：`node tools/audit_coverage.mjs`
- 核验台账：`node tools/audit_verification.mjs`。它只报告被自动化测试引用的卡牌，不能代替逐条官方效果核验。

2026-09-14：56 项测试通过，其中四组包含 48 局起始牌组自动对局；手机 390 像素及桌面 1440 像素操作检查通过。专项检查包括费用非法操作回滚、KO 替代、返还七张 DON!!、强制抽牌、满场生命触发登场、特殊同名卡数量与手牌费用减免。自动对局不代表全部卡牌效果已经验证。

## 继续开发

1. 迁移剩余原生／旧版特殊规则，并对照原始效果及原程序验证；重点检查同时触发的顺序、复合步骤与连续多卡登场。
2. 补齐中文说明与缺失原图；未取得原图不能用仿制图冒充。
3. 扩充真实卡牌回归场景，检查被动条件、效果目标与失去效果后的行为。
4. 完成全卡池可用性、手机体验及部署验证，再交付正式链接。

前端位于 `dist/`；规则引擎为 `dist/engine.mjs`；原规则图为 `dist/data/rules.json`；迁移脚本在 `tools/`。`tools/extract_rules.py` 会覆盖已转换的旧版规则，重跑后需要执行 `tools/convert_legacy.py`。`tools/wire_app.py` 是一次性脚本，不可重复执行。

已注册的 Sites 项目保存在 `.openai/hosting.json`。发布时复用该项目，不能把未发布的预览地址当作正式链接。

## 本轮规则迁移

新增原生规则：卡名／颜色事件／攻击属性例外、目标条件的备选分支、连续登场不重复卡名、己方和对方场上费用修正、攻击属性战斗保护、KO 通知、对方阻挡通知、随机弃手牌、零 DON!! 的特殊发动条件、对方角色力量阈值。

检索整副牌库／弃牌区／手牌时先筛选候选池，不再多问一次无意义的选择。费用计算只求值与费用有关的被动效果，避免力量条件反过来查询费用时出现循环。目标结构审计同时检查备选条件中的字段，未实现的字段仍然阻止开局。

本轮新增 12 个真实卡牌场景，见 `tests/rules-expansion.test.mjs`；覆盖 ST03 检索、ST08 保护及 KO、ST10 阻挡响应和弃牌、ST12 属性例外、ST13 不重名登场、ST14 费用叠加。总计 71 张卡不再含未实现字段，不能据此声称这 71 张已逐张通过所有组合验证。

后续重点仍包括回合结束延迟结算、旧版规则转换、同时触发的可选结算顺序、复杂多步骤费用及特殊胜利条件。

## 延迟结算续补

支持 `QueueUpEndOfTurnAction` / `QueuedEndOfTurn`：登记时保存效果，回合结束的一般效果完成后再逐项结算；多个延迟效果可选择顺序。来源离场或被消除效果不会抹掉已登记的义务。自指效果使用卡牌在场身份区分离场重返，避免误影响重登场的卡牌。登记队列和正在处理的选择都可随对局存档及撤销恢复。

支持黑色玛利亚按双方当前 DON!! 差额返还、ST13 生命牌重排（保留正反面）及丢弃全部正面生命。修正“场上没有其他同名角色”条件误把来源自己计入的问题。

新增 `tests/end-turn.test.mjs` 的 9 个场景，总计 56 项测试通过；`tools/qa_endturn.py` 验证手机端保存及恢复延迟顺序选择。未实现字段涉及的卡牌由 571 降至 560；这仍不是全部卡牌逐张验证的计数。
